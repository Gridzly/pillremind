# Medminder
### **Medminder – How It Works**

**Medminder** is a smart medication management system that connects users through a mobile application and an automated medicine dispenser.

**Types of Users:**

1\. **Authorized Person (Caregiver)**

- Adds and manages medicines.
- Sets medication schedules.
- Monitors the patient's medication activities and history.

2\. **Patient (Medicine Taker)**

- Receives medication reminders.
- Views scheduled medicines.
- Checks medication history and reminders.

**System Integration:**

- **Mobile Application:** Manages accounts, medicines, schedules, and notifications.
- **Automated Dispenser (ESP32):** Rotates to align the correct medicine compartment at the scheduled time.
- **Firebase:** Synchronizes data between the application and hardware.
